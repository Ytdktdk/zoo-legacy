# Стратегия тестирования

## 1. Описание подходов к тестированию

Тестирование проекта «Генетический симулятор зоопарка» проводится по принципу «пирамиды тестирования»: от модульных тестов на нижнем уровне до ручного приёмочного тестирования на верхнем. Особое внимание уделяется корректности алгоритмов генетики, так как они являются ядром игрового процесса.

## 2. Уровни тестирования

### 2.1. Модульное тестирование (Unit Testing)
- **Что тестируется:** Отдельные функции и классы (расчёт наследования генов, формулы мутаций, валидация входных данных).
- **Инструменты:** Unity Test Framework / NUnit.
- **Целевое покрытие:** Не менее 80% критически важных модулей.
- **Примеры проверок:**
  - Наследование доминантного гена окраса при скрещивании гомозиготных особей.
  - Граничные значения шанса мутации (0% и 100%).
  - Корректная работа формулы редкости при нулевом базовом шансе (защита от деления на ноль).

### 2.2. Интеграционное тестирование (Integration Testing)
- **Что тестируется:** Взаимодействие между системами игры.
- **Примеры проверок:**
  - Система «Животное» ↔ «Вольер»: животное не может покинуть вольер, еда корректно списывается из склада при кормлении.
  - Система «Генетика» ↔ «Сохранения»: гены потомка корректно сериализуются и десериализуются.
  - Система «ИИ» ↔ «Коллайдеры»: животные не проходят сквозь стены.

### 2.3. Нагрузочное тестирование (Performance Testing)
- **Что тестируется:** Стабильность FPS и потребление памяти.
- **Сценарии:**
  - 100 животных на сцене — целевой FPS 60.
  - 300 животных на сцене — целевой FPS не ниже 30.
  - Длительная сессия (2+ часа) без утечек памяти.

### 2.4. Ручное тестирование (Manual / QA Testing)
- **Что тестируется:** Пользовательские сценарии, UI/UX, игровой баланс.
- **Кто проводит:** Разработчик + тестировщик (или заказчик на этапе UAT).

## 3. Критерии начала тестирования

Тестирование релизной версии начинается только при выполнении всех условий:
- Код заморожен (Code Freeze), все фичи влиты в ветку `main`.
- Сборка проходит без ошибок компиляции.
- Все модульные тесты проходят успешно (зелёный билд).
- Тестовая сборка развёрнута на тестовом стенде.
- Подготовлены тестовые данные (сохранения с разными стадиями игры).

## 4. Критерии окончания тестирования

Тестирование считается завершённым, когда:
- Выполнено 100% тест-кейсов из чек-листа.
- Отсутствуют открытые баги с приоритетом **Critical** и **High**.
- Баги с приоритетом **Medium** и **Low** задокументированы и согласованы на перенос в следующий релиз.
- FPS не падает ниже 30 на целевом оборудовании (GTX 1050, 8 GB RAM).
- Подписан акт приёмочного тестирования (если требуется).

## 5. Чек-листы ручного тестирования

### 5.1. Модуль «Генетика и размножение»
- [ ] Скрещивание двух животных с разными доминантными генами даёт потомка с корректной комбинацией.
- [ ] Рецессивный ген проявляется только при наличии двух копий.
- [ ] Мутация происходит с заданным шансом (проверка на выборке 100+ потомков).
- [ ] Статистика редкости мутации отображается корректно.

### 5.2. Модуль «Вольеры и содержание»
- [ ] Животное нельзя поместить в переполненный вольер — появляется предупреждение.
- [ ] Животное не может выйти за пределы вольера (коллайдеры работают).
- [ ] При удалении вольера животные корректно перемещаются в резервный.
- [ ] Уровень счастья животного меняется в зависимости от условий.

### 5.3. Модуль «Сохранения и загрузки»
- [ ] После сохранения и перезапуска игры возраст, гены и координаты животных сохраняются.
- [ ] Сохранение не вызывает заметного фриза (не более 0.5 сек).
- [ ] При повреждении файла сохранения игра предлагает создать новое, а не падает.

### 5.4. Модуль «Интерфейс (UI)»
- [ ] Все элементы UI читаемы при разрешении 1920×1080 и 1280×720.
- [ ] Интерфейс не выходит за границы экрана при изменении размера окна.
- [ ] Все кнопки имеют визуальный отклик при наведении и нажатии.
- [ ] Тексты локализации не вылезают за рамки кнопок.

### 5.5. Модуль «Производительность»
- [ ] При 100 животных FPS стабильно 60.
- [ ] При 300 животных FPS не опускается ниже 30.
- [ ] Загрузка сцены занимает не более 10 секунд.
- [ ] Отсутствие утечек памяти при длительной игре (2+ часа).
