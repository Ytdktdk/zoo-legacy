# Стратегия тестирования

## Уровни тестирования
1. Unit-тесты: проверка алгоритмов наследования генов (доминантные/рецессивные признаки).
2. Integration-тесты: проверка взаимодействия систем "Животное" и "Вольер".
3. Ручное тестирование: проверка UI и игровых сценариев.

## Чек-лист ручного тестирования
- [ ] Скрещивание двух животных дает потомка с корректной комбинацией генов.
- [ ] Попытка добавить животное в переполненный вольер выдает ошибку, а не краш.
- [ ] После сохранения и перезагрузки игры возраст и гены животных сохраняются.
