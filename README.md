# Zoo Legacy
Проект генетического симулятора зоопарка.

## Описание
Симулятор, в котором животные обладают набором генов, передающихся по наследству. Игатель может скрещивать животных, управлять вольерами и наблюдать за эволюцией видов.

## Структура проекта
- `/docs` - техническая документация
- `CHANGELOG.md` - история изменений
